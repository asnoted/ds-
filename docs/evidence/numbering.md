## 票也改齐了(2026-10-18)

**为什么动**: 早先的口径是"票是当时的记录, 不替它改号"(旧 0001 决定 4 原话), 靠这张表给
读者查. 2026-10-18 人拍板改成对齐 -- 票里的引用要能直接点得进去, 不该多一步"查表".

**怎么改的**: 只动 `ADR-NNNN` 与 ADR 篇的路径, 每个号照上面那张表; 并列写法里两个号若落到
同一篇就并成一个(比如 0026/0027 都进了当时的 0010). 正文顶上加了一条注(写清这次动过什么),
跟着旧篇走的行号(诸如 0014 那篇的 `:44-45`)一并去掉 -- 那些行号指的原篇已经不在, 留着更像
是指对了. 措辞与其余内容一字未动. 规模: 正文 31 张, 评论 42 条.

**工具只报了 15 张, 实际 31 张**: `--citations` 只扫**正文**, 而且只认"当前语料里指不到"的
号 -- 旧号里有几个(0002 / 0004 / 0010 / 0011 / 0012 / 0013)与当时的号撞号, 落在这些号上的
引用在工具眼里是"指得到", 就漏了; 评论那一半它根本不看. 这次是把所有票按 `updatedAt` /
`createdAt` 早于重编号那一刻(2026-10-17 22:38, 就是那一笔 d2ecb24)全过了一遍才找齐.

**两处故意没动**: #27 与 #25 的评论里写着当时的 0009(当时记的是宿主的模型钉法), 那是比这
28 篇更早的一轮里的篇, 当前语料没有它的家; 那两处引用的意思恰恰是"这个前提没了"(两票都因此
wontfix), 改掉反而把话改反. #15 与 #27 的 0007(动作流)正好等于当时的 0007, 不用动; 那篇在
2026-10-19 已删.

**改之前的样子**: 每张票的原件留在那次跑批的临时目录($TMPDIR 下的 ds-issue-bodies-orig /
ds-issue-comments-orig), 临时目录随时可能被清; 要真回退就照这张表反着改 -- GitHub 对评论留
着编辑历史, 正文没有.
