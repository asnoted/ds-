## 补记:答复要认 id(2026-10-17,#108)

ADR-0002 决定 1 那道只管**发出去**的那一趟;"回来"的那一趟原先没有归属判据,于是留了一条同形的岔路.

页面世界排一圈围栏(`call` 信封,带 `id`),隔离世界跑完把答复投回来(`result` 信封,
同一个 `id`).收信那一侧**不看 id**:谁的 `result` 进来都当"这一轮的工具结果回来了"
排进续聊.探针 `scripts/page-action.py` 正是用同一条链驱动本地工具的--它投一条
`{"tool":"send.page",...}`(id 形如 `probe-send-page-...`),在信封上与一轮真围栏一模一样,
答复也一模一样地回来.于是**每跑一次 `send-page`,续聊就多拿到一个"工具结果",凭空多发
一条 `agent:继续`**,而且那条的正文是探针的答复,不是真工具结果.

12:56:03 那笔 `send-failed` 就是这么来的:模型正在答上一条真 `继续`,这条撞上去,Enter
与圆键都发不出去(抓到的帧上:模型正在生成).同一处对话里还留着更早的现场:两圈围栏
之间,对话留下了**三条** `agent:继续`,其中一条前面没有围栏.

判据收在 `src/lib/fencecalls.ts`:排 `call` 时记下 id,收 `result` 时**只认自己排出去,
还没收过的那一个**,别的丢掉并在控制台留一行(信封上有 id,不必猜).一轮一次--重放与
重投一并挡住;名单 FIFO 有界(16 个),漏掉的答复挤掉最老的.探针不受影响:它驱动工具走
的是隔离世界那条路,判据读的是页面状态(`landed` / `composerAfter` / 账本),不靠这一跳.

**真机复验(2026-10-17,闸开着)**:环境先按 `scripts/env-up.sh` 换成本仓当时那版(构建比
源码旧,跑之前是旧扩展),再用 `send-page --send` 连跑四轮**带真围栏**的问题--前三轮各发
一次 `read`,末一轮 `grep` 与 `read` 并排各一次.四轮都是:围栏一条,`agent:继续` **恰好
一条**,没有凭空多出来的那一条;账本 20 笔痕 / 3 帧四轮没动.修之前正是**探针自己的**
`send.page` 答复多喂进一轮(探针每跑一次就多一条 `agent:继续`),这条现在也验掉了:同一次
复验里探针的答复不再被当成工具结果.
后三轮的正文成了那几道上限的读页证据(旧 0010;单行标注, 翻页脚注, 整页 13,492 字,
`grep` 与 `read` 两种前缀并排).

顺带一件事:那笔 12:56:03 的 `send-failed` 头痕在这两轮之后**已恢复**(`recoveredAt` 落上,
头不再红)--旧扩展里那一下是模型正答上一条真 `继续` 时被挤进来的,新代码没再发生.

## 2026-10-20 判定注记(#110)

- **#108 的真机复验**是 2026-10-17 那四轮, 证的是 `fencecalls` 只认自己排出去的 `result`;
  2026-10-20 的会话归属修复(`e240d98` / `53f1e7d` / `a3bc70d`)之后没有在真机上重跑. 代码里
  这一跳没有换 (`fencecalls` 的名单 / 会话映射照旧), 但"当前实现"的真机读数仍是缺的.
- **8 轮刹车, 16K/轮, 8 块/轮**有 CI 用例 (`rounds.test.ts` / `continuation.test.ts` /
  `fenceround.test.ts`); 真机只读到过 13,492 字的那一页, 没有把 8 轮跑满, 也没有撞过贴边截断.
- **首条消息从 `/` 进入**时 `pageSessionIdOf` 是 null; 接线侧用 `roundSession ?? current` 把答复
  归到站点新建出来的会话. 这是代码与单测口径, 没有单独的真机现场.
- **总开关 / popup 默认关**有 `toggle.test.ts` 的存储判据; 真机上一直是用 `storage set` 开的,
  没有点过 popup 的那颗开关. 选项页的 `speak` 勾选有 2026-10-11 的真机读数.
- **闸关时 stage-only** 的真机读数在 2026-10-11 / 2026-10-18 (`speak-gate.md`); 当前
  `inject.content.ts` 的 `stage` 分支仍是"只写输入框, 不碰 Enter", 判定清单里也只有
  `{ kind: "stage" }`.
- **原生 `chat/continue`**: 已调研, 决定不用 (`native-continue.md`), 不算未交付.
