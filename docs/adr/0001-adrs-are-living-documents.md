# ADR-0001: ADR 是活文档:就地改, 一次性的实测进 `docs/evidence/`

- **Status**: accepted
- **Date**: 2026-10-17

每篇 ADR 写的是**当前口径**, 不是决策日记. 口径变了就改那一篇(连 `Date` 一起改),
而不是另开一篇去"修订/取代"它; 一次性的实测(探针原始读数, 时间线, 账本数字, 失败痕)
搬进 `docs/evidence/`, ADR 正文里只留一句点名.

为什么改这条: 2026-10-17 之前这里躺着 28 篇, 其中 13 条边是"只修订某篇一点"
(0032 修 0027, 0034 修 0016 与 0033, 0035 修 0026 与 0032 ...). 后果有两样, 都实测过:

1. **同一主题的当前真值要拼 5~6 篇**. "额度"这一条要读完 0014 / 0016 / 0026 / 0027 /
   0032 / 0035 才知道现在是多少.
2. **被推翻的句子永远以现在时留在原地**. 旧 0014 写着 `MAX_RESULT_CHARS = 2000`,
   而代码是 16,000(`src/lib/continuation.ts`); 旧 0002 写着"开窗 3~5 秒", 而现在是
   Beta(2,4) 的 3~15 秒. 规则原文是"已接受的 ADR 不可变, 旧文件一个字不改" --
   于是读者按字面读, 读到的是错的.

## 决定

1. **一篇一个主题, 写当前口径**. 改口径 = 改那一篇; 整个主题不存在了 = 删那一篇.
   没有 `Supersedes` 链, 没有"只修订 X 的一点"这种篇.
2. **骨架固定**(由 `tests/test_adr_corpus.py` 钉着): 落在 `docs/adr/`, 文件名
   `NNNN-kebab-title.md`; H1 是 `# ADR-NNNN: 标题`(编号与文件名一致); 头两行 `Status` /
   `Date`(没有 `Supersedes` -- 演进不再靠"谁取代谁"这张图); 下面一句开篇段; 四个固定节按序
   到齐: `## 决定` / `## Considered Options` / `## Consequences` / `## 判据(怎么自己复现)`.
   别的节(已知洞 / 未验证项 / 自己的小节)随便加.
3. **一次性的实测不进正文**, 进 `docs/evidence/`. 判据是"别人照着能不能自己复现":
   能(测试名, 命令, 常量名, fixture 路径)就留在 ADR 的 `## 判据` 里, 不能
   (某天某点的探针读数, 账本上的某几笔)就进 evidence, 正文点名一句. 留下的判据要**真的
   会咬**: 命令跑绿不算数 -- 得对着它那句注释确认它查的是那件事(2026-10-17 夜里就抓到
   一条 `-k token`, 收集到的是另一个测试, 绿得毫无意义). 块里点着的路径也由守卫核
   **在不在**(路径没了, 那句判据就成了空话): 核的是存在性, 跑起来对不对仍要人跑一遍.
4. **引用要指得到**. 引用 `ADR-NNNN` 就必须有那一篇; 重编号时全仓引用一起改
   (注释, 测试标题, fixture 的 `description`, 探针的 report 字符串都算引用). **有守卫**:
   `tests/test_adr_corpus.py` 扫全仓, 并列写法(`ADR-0007/0006`)里每个号都算, 有一个指不到
   就红 -- 本篇落地那天是靠人肉 `grep` 扫的, 扫出 6 处悬空. 篇内的 `决定 M` 也算引用, 而
   M 是**下标**: 号还在, 下标搬歪了这条查不出("那一篇里没有第 M 条"查得出, 同一道守卫);
   并决定 / 删决定时, 篇外那些下标要自己回头改. 实测段搬进 `docs/evidence/` 之后同理:
   那里面"那一篇的某节"要改成"本篇那节"(同一个夜里清掉九处这样的指向, 守卫也查不出).
5. **索引 `docs/adr/README.md` 由脚本生成**: `uv run scripts/adrs-index.py`
   重新生成, `--check` 接在 `pnpm quality:ci` 里. 手改索引会判红.
6. **文档布局**: 根目录只许 `AGENTS.md` / `README.md` / `GLOSSARY.md`, 别的文档一律进
   `docs/`. 技能流程用 Matt 那套(`.agents/skills/`, 版本记在 `skills-lock.json`);
   `docs/agents/*.md` 记 issue 追踪, 分诊标签, 领域文档的规则. **没有 spec 目录**:
   `openspec/` 那套(2026-10-04 到 10-07)整体退役 -- 没有工具校验的 spec 必然过时, 而过时的
   契约比没有契约更误导; "必须怎样"改由 `GLOSSARY.md`, ADR, 测试, `protocol/fixtures/action.json`
   与 `protocol/evidence/controls.json` 承载. 所以代码注释里"见某 spec"都是**历史指向**
   (原文在 git 里), 去处看这一条.
7. **词汇表管词**: 输出提到领域概念时用 `GLOSSARY.md` 里的词, 不要漂到同义词.
8. **点名的东西要在**. 篇里反引号点着的路径与标识符是**指路牌**: 代码里改了名, 文件挪了家,
   牌就得跟着换 -- 否则读者按它去翻会翻空. **有守卫**: 同一道(`tests/test_adr_corpus.py`)
   扫 13 篇加 `README.md` / `GLOSSARY.md` / `docs/CODING_STANDARDS.md` / `docs/probe.md`
   这四份, 篇里每一处路径 / 常量 / 标识符都核, 连 pytest 的节点号写法也一起看(换面 / 加面
   要连着这一句一起改 -- 有个用例盯着这两处一致). 真在仓外的东西(站点端点与
   localStorage 键, MCP 协议字段, 用户本机的 `mcp.json`, Considered Options 里被否决的
   目录)进一条**显式白名单**, 每条写清为什么; 白名单以外缺一个就红 -- 常量被改名的那种漏,
   这一条专治. `docs/evidence/` 不在扫面里: 那些是来历, 旧名字是它的证据.

## Considered Options

- **保留"已接受 ADR 不可变 + `Supersedes` 演进"**(旧规): 否决. 它的好处是历史完整,
  代价是读者被骗 -- 而且被骗的那一类句子恰恰是数值与现状(见上面第 2 条的两个实例).
- **ADR 只记"为什么", 另建一份"当前真值"页**: 否决. 两块地方必漂; 而数值本来就有测试
  与 README 的限额表在守, 再加一层只是多一处要同步.
- **旧篇归档进 `docs/adr/archive/`**(生成器是非递归 glob, 挪进去就自动跳过): 否决.
  归档和留在原地对读者是同一件事 -- 谁翻到那篇, 谁就按字面读.
- **保留 `Supersedes` 机制只用于"整篇被推翻"这一种**: 否决. 那正是最该就地改的一种;
  留着它等于给"另一处真值"开口子.

## Consequences

- **读一篇就够**: 每篇开头那段就是当前口径, 不必先去考古.
- **代价: 历史只剩 git 与 `docs/evidence/`**. 要"当时为什么这么定"的完整时间线,
  去 `git log` 或 evidence 文件, ADR 不再承担这件事.
- **编号不再是对旧语料的单调延伸**: 2026-10-17 这次重写把 28 篇并成 13 篇并重新编号,
  旧号只在 `git show` 里有意义. 那次合并的映射写在提交信息里.
- **重编号不追仓外的引用**: 票(GitHub issue)的正文与评论是仓外的记录, 而且已关的票记的
  是"当时的想法" -- 不替它改号. 哪几张还牵着旧号由
  `uv run scripts/audit-issues.py --citations` 报出来(信息级, 要 `gh` + 网络): 语料里没有
  的号它指得出来, 而号码落在 `0001..0013` 之内, 当时却指别的篇的那几处它查不出.
- **`docs/CODING_STANDARDS.md` 第 2 节("修订型 ADR"那条)随之作废**, 改成"活文档"这条的
  投影; `docs/agents/domain.md` 末尾那句"不可变"也一并改掉.
- **守卫只查形状, 不查内容**: 骨架与全仓引用由 `tests/test_adr_corpus.py` 守, 索引由
  `scripts/adrs-index.py` 守; "这篇写的是不是当前口径"没人守 -- 那得读的人自己核代码.

## 判据(怎么自己复现)

```sh
uv run scripts/adrs-index.py --check      # 索引与正文一致
pnpm relay:test                           # 骨架 / 引用 / 篇内下标 / 点名的东西(tests/test_adr_corpus.py)
pnpm quality:ci                           # 三道守卫: 中文标点 / 混入文字体系 / ADR 索引
uv run scripts/audit-issues.py --citations   # 仓外那些票里的旧号(信息级; 要 gh + 网络)
```
