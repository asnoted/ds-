# ADR-0002: 续聊替换: 一轮可排多块

- **Status**: accepted
- **Date**: 2026-10-22

工具结果作为一条可见的长消息回灌
一轮里模型可以排多块围栏, 各块各打一趟网关.

## 决定

1. **正文改走消息窗**:
2. **结果截断 `MAX_RESULT_CHARS = 16_000`**
3. **一轮多块**:
   按出现顺序取出所有块, **一轮最多 9 块**(`relay.ts` 的 `MAX_CALLS_PER_ROUND`), 超出部分下一轮再排, 末句说明还有几块没执行.
   只读的 `read` / `glob` / `grep` 排进围栏后**自动放行**(名单在 `src/lib/approval.ts`); 其余工具等用户点「执行」/「跳过」.
4. **答复认 id**: 排 `call` 时记下 id, 收 `result` 时**只认自己排出去,还没收过的那一个**
5. **用站点原生的输入**
6. **全部工具结果收回后在插入**

## Consequences

- **用户消息可见"**; 工具结果人类可读(用toon).
- **块数上限从 8 提到 9**; 只读工具自动放行不改变"会改状态的工具仍要人点"这条边界.
