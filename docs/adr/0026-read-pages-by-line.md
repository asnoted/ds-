# ADR-0026: `read` 按行翻页:一页带上行号与"接着读",扩展侧那一轮不再腰斩

- **Status**: accepted
- **Date**: 2026-10-08
- **Supersedes**: none

本篇**只修订三篇里各一个点**,其余一律不动:ADR-0012 的 `read` 形状与上限,ADR-0014 的
扩展侧正文上限,ADR-0016 那句"两道各管一段"的数值.**那三篇都不因此改动.**

## 问题

`read` 一次读一个文件,超 16000 字就砍一刀加一句"已截断".而扩展侧把工具结果回灌进
对话时另有 2000 字的上限.两个数一撞,模型看到的就是:

```
dsb 交出      16,000 字
回灌进对话     2,000 字   ← 12.5%
翻页能力      没有
```

**模型看不到其余 87%,而且没有任何办法看到.** 再 `read` 一次拿到的还是开头那几个字
\--`read` 没有 `offset`,也没有 `totalLines` 能告诉它自己在哪.

截断那句文案也帮不上忙:`...(已截断,超出 14464 字符)`.模型拿着它只知道"少了",
**不知道少了哪些,在哪,怎么接着看**.

参照:[ADR-0025](./0025-structured-content-is-declared-not-guessed.md) 末尾"12%"那节
记的就是这个数,并指出形状可抄 DeepSeek Harness 的 `read`(`offset`/`limit`,行号,
三态脚注).那是本篇的来源.

## 决定

### 1. `read` 按行翻页,正文带行号,末尾一句脚注

`offset` 是 1-based 起始行号(默认 1),`limit` 是读多少行(默认 200,最多 2000).
正文逐行带 `N: ` 前缀,末尾一句脚注,**三态各自说清读到哪**:

```
1: ...
2: ...
(第 121-200 行 / 共 843 行,接着读:offset=201)   ← 页到头,文件还有
(字节预算截断,第 1-200 行 / 共 843 行,接着读:offset=201)  ← 预算砍在半路
(文件读完:共 843 行)                            ← 读完,不编下一步
```

**只有真有下一读的那种才给 `offset=`**--"读完"那句不给,不然模型会去读一个不存在的
第 844 行.

按行不按字符(ADR-0026 的 Q3 决定):模型想的是行,`grep` 也是行向的;而按字符会让
`offset` 落在一行中间,对行向的思考没有帮助.

### 2. 上限从一个总数变成四个各管一件事的数

`WORK_READ_LIMIT`(16000)删掉,换成:单页默认 200 行 / 单页上限 2000 行 / 单行 500 字 /
单次字节 16000.**加行号之后每行大约多 6 字**,所以单行上限跟 `grep` 共用同一个 500 的
量级是合适的.

**单行超限另标**(`...(本行超 500 字)`):静默截断会让模型以为那就是整行.

**预算小到一行都放不下时仍然给那一行**(哪怕超预算):空页对模型最没用--它拿不到任何
内容,连翻到哪都不知道.

`offset` 越界回新错码 `bad-range`(从 1 起,至少 1 行这两个是入参约定,越界当错码回,
不静默改成别的);`limit` 超上限按上限给而不是报错(模型把 99999 写进来也能拿到一页).

### 3. "逐字"那条承诺改成它真正保证的那句

ADR-0012 与 `GLOSSARY.md` 给 `read` 的保真口径里含"逐字".**带行号之后它不再是逐字的.**
不改的是它的实质:不丢,不猜,不改写内容--**行号是呈现层的前缀,正文内容一字未改**.
`GLOSSARY.md` 的"工作工具"条目照改,协议说明里明写"行号只是前缀".

这是本篇唯一一处**措辞**的修订,实质能力没有放松:模型看到的每一行内容仍与文件逐字相同,
多出来的只是行号与脚注.

### 4. 扩展侧那一轮从 2000 放宽到 16000

`src/lib/continuation.ts` 的 `MAX_RESULT_CHARS` 与 dsb 的 `WORK_READ_BYTES` **同数**,
于是**一页 `read` 的结果能原样进对话,不再被腰斩**(2026-10-17 补:一页的额度从此连脚注
与换行一起算,这句话才真的成立--原先贴边时脚注会被扩展从尾巴上截,见
[ADR-0035](./0035-the-budget-includes-the-closing-line.md)).

注意这**不是**网关那道传输与内存的闸(`dsb/gateway.py` 的 64K,ADR-0016)--那道管的是
失控结果(几十兆的目录树)灌满内存与存储.ADR-0016 那句"两道各管一段,别混"仍然成立,
只是第二道的数值变了:2000 → 16000.

**ADR-0014 也记着那个 2000**(`扩展侧 MAX_RESULT_CHARS = 2000`),本篇一并修订该点.

## Considered Options

- **只放宽回灌上限,不加翻页**:模型能看到更多,但一次仍只能看开头--16000 字之后的
  依然永远看不到,而文件可以比 16000 大得多.否决.
- **按字符翻页**:模型算得准,但 `offset` 落在一行中间,行向的思考用不上.否决.
- **不带行号,只补位置与翻页**:保住"逐字"字面,代价是模型看不到行内位置,引用与
  诊断都受益不了.否决--而 #89 要保的那条实质(不丢不猜不改内容)行号并不违反.
- **做 tail / 头尾混合**(给日志用):范围外.`grep` 加翻页够用了,真需要再说.
- **`limit` 越界报错**:模型写个 99999 就整轮作废,而给上限它照样拿到一页.否决.
- **顺带把 `grep` 换成 vendored ripgrep**(`@vscode/ripgrep` + `rg --json`,ADR-0025 末节
  查过):省维护,引擎成熟,方言在工具描述里公开声明.**另开一票**,不与本篇混在一处
  --两件事的回归面不同,混在一起 diff 不好读.

## Consequences

- **模型看大文件不再停在 12%**:一页 16000 字原样进对话,且**它知道接着读什么**.
- **`read` 的输出形状变了**,三处测试从"逐字等于文件内容"改成"逐字等于带行号的那页"
  (`test_work.py` / `test_work_permissions.py` / `test_mcp_server.py`).它们钉的是**新
  契约**,不是放宽--行号与脚注都在断言里.
- **协议说明加了一行**教模型按脚注翻页,工具描述也写了 offset/limit 的用法;工具目录是
  动态的(`tools/list`),`read(path, offset?, limit?)` 那行自动更新.
- **旧的不等式不再成立**:以前"dsb 交出 16000 / 回灌 2000"是 12.5%,现在两边同数.
  `continuation.test.ts` 里钉了这个不等式,别让它悄悄回去.
- **`read` 的三个上限都可能配出来**:四个数都在 `dsb/work.py` 顶部,与 `grep`/`ls` 那组
  并列.
- **真机待验**:见下.

## 真机验证(2026-10-17): 整页原样进对话

**为什么验这条**: 本篇改的是"dsb 交出一页 16000 字"与"扩展侧那一轮不再腰斩"两边**同数**.
在这之前 2026-10-11 那次探针只送过 149 行 / 5,251 字--**远在旧的两千字以内**, 所以
"两边同数"这一层其实没被碰过. 要碰它, 结果得**明显大过 2000 字**, 而且证据要落在旧闸
够不着的地方.

**设置**: `toggle: true`, `speak: true`(闸开着, 扩展自动续). 问题走真机探针
`send-page --send` 真发进对话.

**造素材**: 100 行 / 13,086 字的 ASCII 文件, 每行约 124 字, **末行只埋一个唯一标记**
`ZK-PAGE-EDGE-9931`. 先在本仓用 `read_text` 算过: 整页渲染 **13,492 字**, 末尾脚注
`(文件读完:共 100 行)`--即"一个默认页装得下", 而它是**旧两千字闸的 6.7 倍**.

**走查**: 让模型 `read tmp-page-probe.txt`, 不翻页, 抄最后一行原文与末尾脚注.

**模型答**(逐字):

    一,最后一行原文:
    100: ZK-PAGE-EDGE-9931
    二,末尾脚注原样:
    (文件读完:共 100 行)

**结论**: 13,492 字那一页**整页到了模型手里**--标记落在整页一万三千字开外, 旧的两千字
闸根本够不着它; 而模型把脚注与正文("去掉行号前缀就是那一串")都报得分明. "两边同数"
这条在本机上站住. 同一轮还顺带量出两个数: **前缀开销** 406 字 / 100 行(约 4 字/行,
含脚注), 以及**三位数行号**不被当成正文(n=2, 上一次是两位数).

**顺带**: 这一轮同时是 ADR-0014 补记 #108 的第三轮(围栏 1 条 -> `agent:继续` 恰好 1 条,
账本 20 笔痕 / 3 帧没动).
